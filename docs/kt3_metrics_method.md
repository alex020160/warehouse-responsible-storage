# Подсчёт объёма производственного кода

Актуализация: 24.11.2026, после исправлений по рецензии.

| Версия | Файлы | Физические строки | Непустые строки | Структура |
|---|---|---|---|---|
| Python | 4 | 876 | 806 | 33 функции |
| Java | 19 | 882 | 832 | 18 классов, 1 интерфейс, 115 методов, 18 конструкторов |

Python: только `src/*.py`. Java: только `src/java/src/main/java/**/*.java`.
Физические строки считаются через `read_text(encoding="utf-8").splitlines()`;
непустые — через `bool(line.strip())`. Комментарии включаются.
Стенды, документы, данные и результаты сборки исключаются. Функции Python
подсчитываются по AST; Java-типы, конструкторы и методы — по javap -private
без синтетических методов лямбд. Исправления не изменили состав публичных методов.
Машинные значения сохранены в [kt3_metrics.json](kt3_metrics.json).

Увеличение Java с 850 до 882 физических строк относится к проверке исходных
полей JSON и входных дат. Метрики описывают размер реализации, а не качество.
