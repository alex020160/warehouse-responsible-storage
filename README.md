## Тема проекта

Автоматизация процесса приёмки товара на ответственное хранение.

## Описание проекта

Проект выполняется в рамках учебной практики и посвящён исследованию и автоматизации процесса приёмки товара на ответственное хранение.

Рассматриваемый бизнес-процесс включает:

- регистрацию ожидаемой поставки;
- проверку сопроводительных документов;
- идентификацию товара;
- количественную и при необходимости качественную приёмку;
- регистрацию расхождений;
- фиксацию фактически принятого товара;
- выбор места хранения;
- регистрацию размещения товара на складе.

## Цель проекта

Разработать проектное решение для автоматизации процесса приёмки товара на ответственное хранение, включая описание бизнес-процесса, проектирование данных и последующую программную реализацию.
