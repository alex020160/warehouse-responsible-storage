`parity-input.json` — полные запросы; `parity-python.json`, `parity-java.json` —
фактические ответы; `parity-results.json` — результаты по именованным случаям.
Массивы не сортировались. null, даты, количества и типы расхождений сравнивались
без нормализации. Для отказов сравнивались факт отказа и неизменность состояния,
а не дословный текст сообщений разных языков.

Самопроверка Java дополнительно повторяет все 41 эталонных случая и проверяет,
что попытка сохранить повреждённый остаток отклоняется до записи, прежний файл
сохраняется и временные файлы не остаются. Это проверка реализации КТ3, а не
полный этап тестирования КТ4 и не рецензия одногруппника.

Linux/macOS и конкретная Run-конфигурация IntelliJ не запускались. Для Python
выбран встроенный терминал IDE; пользователь подтвердил отсутствие прежнего запуска.
